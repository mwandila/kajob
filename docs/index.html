Kajob WordPress Theme

Installation and setup guide for Kajob, a job-board theme designed to work with WP Job Manager.

Requirements: WordPress 6.4 or newer and PHP 7.4 or newer. Install and activate the Kajob Core companion plugin supplied with the theme release, plus WP Job Manager for job listings, employer dashboards, submissions and applications.

Install and activate

  1. In WordPress, open Appearance → Themes → Add New → Upload Theme.
  2. Upload the Kajob ZIP, install it, and activate Kajob.
  3. Install the separately supplied Kajob Core ZIP from Plugins → Add New → Upload Plugin.
  4. Install and activate WP Job Manager from Plugins → Add New.
  5. Use the WP Job Manager setup wizard to create the jobs, submit-a-job and job-dashboard pages.
  6. Open Appearance → Customize to set the site logo, colors, home-page copy and optional AI settings.

Demo content

Open Appearance → Demo Content and choose the provided import action. Demo job listings and posts are sample content. Review or remove them before opening the site to applicants.

Menus and pages

Assign navigation menus under Appearance → Menus or Appearance → Editor, depending on the active WordPress menu interface. Kajob creates candidate-account and AI Mode pages when their features are enabled. Job-board pages are managed by WP Job Manager.

Applications and email

Email application forms require an open WP Job Manager listing with an email application method and a valid employer email address. Applicants can submit a short bio, cover letter and PDF, DOC or DOCX documents. Each uploaded file is limited to 5 MB; the combined attachment limit is 10 MB. Configure and verify site email delivery (SMTP is recommended) before accepting real applications. External application links continue to be handled by the job listing.

For Resend delivery, install the separately supplied optional Kajob Resend Mailer ZIP from Plugins → Add New → Upload Plugin, activate it, connect your own Resend account, and verify your sender domain. Configure it under Settings → Resend Email and send a test email before accepting applications. Each buyer must supply their own Resend API key.

Candidate accounts and privacy

Signed-in candidates can save a CV and cover-letter draft. CVs, cover letters and private application details are encrypted in WordPress user metadata and are not placed in the Media Library. Kajob keeps up to 100 recent application records per account until candidate data is deleted or the site administrator processes an erasure request. Site owners should set a retention period appropriate for their business and local laws.

Kajob adds candidate data to WordPress's personal data export and erasure tools under Tools → Export Personal Data and Tools → Erase Personal Data. Erasure removes Kajob candidate metadata and saved-job IDs for the matching account. It cannot recall application emails already delivered to employers or copies retained by email providers. Candidates can delete their saved CV and cover-letter draft from their account page.

Before enabling registrations or applications, publish a privacy policy that explains the data collected, purpose, retention period, contact point and any relevant mail or AI service providers.

Optional AI assistant

The AI assistant is disabled until the site owner configures an API key in Appearance → Customize → AI Assistant, or defines KAJOB_AI_API_KEY in wp-config.php. The default endpoint is NVIDIA's OpenAI-compatible inference API. The site owner must obtain their own key and comply with the provider's current terms, availability and usage limits.

When a visitor uses the assistant, their submitted messages and relevant public listing or blog information may be sent to the configured inference provider. Do not enter sensitive personal information. Tell visitors about this data flow in the site's privacy policy. The theme does not include or pay for an AI API subscription.

Fonts, photos and third-party software

  • Inter and Space Grotesk are bundled under the SIL Open Font License 1.1. The license texts are in assets/fonts/OFL-Inter.txt and assets/fonts/OFL-Space-Grotesk.txt.
  • Original demo SVG illustrations and authorship details are in assets/images/home-demo/ASSET-CREDITS.md.
  • WP Job Manager and Kajob Core are separate plugins. Install both alongside the theme; Kajob Core is supplied as a separate ZIP with the release.
  • Kajob Resend Mailer is an optional separate plugin. If enabled, email recipient/sender details, subject, message body, and attachments are sent to Resend's API for delivery; disclose this service in the site's privacy policy.

Support and updates

For marketplace customers, use the support channel and update instructions listed on the Kajob item page. Keep WordPress, PHP, Kajob and WP Job Manager up to date. Back up the site before theme updates.
