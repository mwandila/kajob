Kajob is a job-board theme built around the WP Job Manager plugin.

== Description ==

Kajob includes responsive job-board layouts, job search and filters, saved jobs, candidate account pages, email applications, demo content, and an optional AI assistant. WP Job Manager and the Kajob Core companion plugin are required for job-board features and are installed separately.

== Installation ==

1. Install and activate Kajob from Appearance > Themes.
2. Install and activate the Kajob Core companion plugin supplied with the theme release.
3. Install and activate WP Job Manager from Plugins > Add New.
4. Use the WP Job Manager setup wizard to create its job-board pages.
5. See docs/index.html for setup, privacy, AI configuration, and asset-license details.

== Privacy ==

Candidate CVs, saved cover letters, and application data are stored as encrypted WordPress user metadata. Kajob supplies personal-data export and erasure callbacks. Site owners should publish their own retention and privacy policies. If configured, the AI assistant sends visitor prompts and relevant public site content to the selected inference provider.
